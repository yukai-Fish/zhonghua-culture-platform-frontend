# 中华文化平台前端

一个深色国风数字展馆风格的“中华文化平台”前端页面。项目以文化地图、文脉长图和本地互动体验为核心，当前完整实现首页与“佛教文化地图”详情页。

## 功能概览

- 首页展示道教文化地图、佛教文化地图、丝绸之路文化地图三大主题入口
- 佛教主题可进入详情页，道教、丝绸之路及更多主题显示“敬请期待”
- 首页包含更多主题入口与主题长卷预告
- 佛教详情页包含佛教地图、佛教文脉长图、文化体验中心和历史时间轴
- 佛教地图支持地点热点与地点简介切换
- 文化体验中心包含与达摩交流、经文释义、愿望摇签、龙门石窟沉浸式视频 demo
- 所有交互均为前端本地模拟，不调用外部 API

## 技术栈

- React
- TypeScript
- Vite
- CSS
- Git LFS，用于管理较大的视频素材

## 本地运行

```bash
npm install
npm run dev
```

默认访问：

```text
http://127.0.0.1:5173/
```

## 构建与检查

```bash
npm run lint
npm run build
npm run test
```

## 项目结构

```text
public/assets       静态图片与视频素材
src/components      页面与功能组件
src/data            素材、主题、地点、经文、签文、时间轴配置
src/styles          全局页面样式
```

## 素材说明

项目使用本地静态素材实现视觉内容，包括道教地图、佛教地图、丝绸之路地图、佛教长图、道教长图、海洋信俗长图以及龙门石窟视频 demo。
