# 上线前检查清单

## A. 资源体积与资源类型
- [ ] 执行 `npm run repo:guard`，确认无压缩包/原始素材误提交。
- [ ] 新增图片是否为可上线资源（优先 `webp`），无冗余大图。
- [ ] 关键页面首屏资源（大图/视频）已做懒加载或预加载策略确认。

## B. 移动端与交互
- [ ] 在 360px、390px、768px 视口检查主要页面排版。
- [ ] 关键按钮/标签点击区 >= 44px。
- [ ] 横向无异常溢出，底部导航与顶部导航无遮挡。

## C. 可访问性（A11y）
- [ ] 核心文案在浅底纹理场景下对比度可读。
- [ ] 键盘导航可见焦点（`focus-visible`）。
- [ ] 语义化图片已补 `alt`，纯装饰图使用空 alt + `aria-hidden`。
- [ ] `prefers-reduced-motion` 下动画与滚动行为可接受。

## D. 构建与部署
- [ ] `npm run lint` 通过。
- [ ] `npm run build` 通过。
- [ ] 工作流改动已检查 YAML 缩进正确。

## E. 页面回归（最少）
- [ ] 首页（入口按钮、视觉主区、导航）
- [ ] 万象图（主题切换、地图热点、长图弹窗）
- [ ] 感应场（木鱼、偈语、摇签、问答）
- [ ] 藏书阁（阅读弹窗、翻页、筛选）
- [ ] 禅修房（卡片布局、输入与按钮状态）

## F. 提交与记录
- [ ] 提交粒度清晰，仅包含本次目标文件。
- [ ] 提交信息可读（`feat/fix/refactor/docs`）。
- [ ] 重要改动同步到 `PROJECT_MEMORY.md`。
